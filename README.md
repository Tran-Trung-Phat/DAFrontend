# 🛒 DAFrontend - E-commerce Web App

This is a frontend project built with HTML, CSS, JavaScript and Next.js.  
The application allows users to browse products, add to cart, and place orders.

🔗 Live Demo:  Live Demo: https://symphonious-shortbread-1e6de7.netlify.app

## ✨ Features

- Display product list
- Filter/search products
- Add to cart
- Update cart quantity
- Checkout system
- Save data using LocalStorage

## 🚀 Highlights

- Fully functional shopping cart system
- Data persistence using LocalStorage
- Clean and responsive UI

## 🛠️ Technologies

- HTML, CSS, Bootstrap
- JavaScript (ES6+)
- DOM Manipulation
- LocalStorage
- JSON
