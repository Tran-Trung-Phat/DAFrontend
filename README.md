# 🛒 DAFrontend - E-commerce Web App

This is a simple e-commerce frontend project where users can browse products, add items to the cart, and simulate the checkout process.

🔗 Live Demo: https://symphonious-shortbread-1e6de7.netlify.app  
💻 GitHub: https://github.com/Tran-Trung-Phat/DAFrontend  

## 🚀 Highlights
- Fully functional shopping cart
- Data stored using LocalStorage
- Responsive design

## ✨ Features
- Display product list
- Filter/search products
- Add to cart
- Update cart quantity
- Checkout system

## 🛠️ Technologies
- HTML, CSS, Bootstrap
- JavaScript (ES6+)
- DOM Manipulation
- LocalStorage
- JSON
